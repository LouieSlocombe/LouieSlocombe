## 🧬 About Me

I'm a [Research Fellow](https://research.birmingham.ac.uk/en/persons/louie-slocombe/) in the [Scanlon Materials Theory Group](https://davidscanlon.com/?page_id=49) at the University of Birmingham. I develop computational and machine-learning methods for sustainable polymer design and predicting environmental biodegradability.

With a background in theoretical physics and chemistry, I also study how quantum effects influence biochemical reactions and how molecular complexity can help us understand living systems. I build and contribute to open-source tools that connect these questions to practical simulations and data analysis.

## 🧠 Research Focus

- **Sustainable polymers:** molecular simulation, AI/ML and environmental biodegradability.
- **Biological systems:** nuclear quantum effects, proton transfer, DNA mutations and protein folding.
- **Assembly theory:** molecular complexity, biochemical reaction networks and life detection.
- **Materials modelling:** amorphous structures, interfaces and photovoltaic materials.

## 🛠️ Featured Code

### Polymers and Materials

| Project | Description |
|---------|-------------|
| [openmmpolymer](https://github.com/LouieSlocombe/openmmpolymer) | Build and equilibrate polymer melts and blends from monomer SMILES, then analyse structural, thermal and mechanical properties with OpenMM. |
| [AmorphGen](https://github.com/SMTG-Bham/AmorphGen) | Generate amorphous structures and ensembles using random placement, melt-quench simulations or hybrid workflows. |
| [solphin](https://github.com/SMTG-Bham/solphin) | Prepare and analyse VASP or CASTEP calculations to assess optical absorption and photovoltaic efficiency limits. |
| [vasp-interactive](https://github.com/SMTG-Bham/vasp-interactive) | ASE calculator for interactive VASP calculations, reusing electronic states through stream and socket interfaces. |

### Reactions and Nuclear Quantum Effects

| Project | Description |
|---------|-------------|
| [reactiontools](https://github.com/LouieSlocombe/reactiontools) | Connect ASE reaction-path calculations, transition-state searches and PLUMED enhanced sampling with reusable analysis and plotting tools. |
| [autopcet](https://github.com/LouieSlocombe/autopcet) | Calculate nonadiabatic proton-coupled electron-transfer rates and kinetic isotope effects, with ASE/ORCA scans and vibronic analysis. |
| [openmmnqe](https://github.com/LouieSlocombe/openmmnqe) | Run OpenMM molecular dynamics with nuclear quantum effects using ring-polymer dynamics and adaptive quantum thermal baths, with isotope and rate-analysis workflows. |
| [openmmqmmm](https://github.com/LouieSlocombe/openmmqmmm) | Couple ORCA and OpenMM for electrostatically embedded QM/MM, with ASE integration and nuclear quantum-effect workflows. |
| [nqetools](https://github.com/LouieSlocombe/nqetools) | Set up i-PI nuclear quantum-effect calculations and analyse instanton rates, tunnelling corrections and kinetic isotope effects. |
| [forcefill](https://github.com/LouieSlocombe/forcefill) | Generate validated OpenMM force-field XML for ligands and unmatched residues using GAFF, OpenFF, Espaloma or supplied CGenFF parameters. |
| [HEOM.jl](https://github.com/LouieSlocombe/HEOM.jl) | Model phase-space quantum dynamics in Julia using Wigner–Moyal, hierarchical equations of motion and Caldeira–Leggett approaches. |

### Assembly Theory and Biochemical Data

| Project | Description |
|---------|-------------|
| [assemblytheorytools](https://github.com/ELIFE-ASU/assemblytheorytools) | Calculate assembly indices and bounds for molecules, graphs and strings; compare shared structure and visualise assembly pathways through a common Python interface. |
| [assemblycfg](https://github.com/ELIFE-ASU/assemblycfg) | Compute upper and lower bounds on string and molecular assembly indices, with RePair assembly pathways. |
| [CBRdb](https://github.com/ELIFE-ASU/CBRdb) | Curated KEGG and ATLAS compounds and reactions, with chemical and thermodynamic properties for biochemical reaction and metabolic-network analysis. |

<sub>The `ELIFE-ASU` tools are collaborative projects from my time with the <a href="https://github.com/ELIFE-ASU">Emergence of Life group</a> at Arizona State University. `AmorphGen` and `solphin` are collaborative projects with the <a href="https://github.com/SMTG-Bham">Scanlon Materials Theory Group</a> at Birmingham. I also contribute to the group's `vasp-interactive` fork of the <a href="https://github.com/tiangroup-uofa/vasp-interactive">original calculator</a>.</sub>

> An **assembly index** measures the fewest joining steps needed to construct an object from elementary parts, allowing previously built intermediates to be reused. [Learn more about assembly theory](https://assemblytheorytools.readthedocs.io/en/latest/).
